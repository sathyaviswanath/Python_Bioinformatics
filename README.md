# DNA Sequence Analysis

## Overview

This project is a Python-based DNA Sequence Analysis tool developed as part of my Python and Bioinformatics learning journey.

The program reads multiple DNA sequences from a text file, validates each sequence, performs various biological analyses, and generates a formatted report automatically.

---

## Features

* Read multiple DNA sequences from a text file
* Validate DNA sequences
* Calculate sequence length
* Calculate GC percentage
* Reverse DNA sequence
* Convert DNA to RNA
* Detect Start Codon (ATG)
* Detect Stop Codons (TAA, TAG, TGA)
* Count nucleotides (A, T, G, C)
* Handle invalid DNA sequences
* Generate a complete DNA analysis report
* Display summary statistics including:

  * Total sequences
  * Valid sequences
  * Invalid sequences
  * Highest GC%
  * Lowest GC%
  * Average GC%
